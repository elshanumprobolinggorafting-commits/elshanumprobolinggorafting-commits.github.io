Pilih Program yang Sesuai

Pilih menjadi Mitra atau Agent sesuai cara Anda ingin bekerja sama dengan Probolinggo Rafting.

🤝 Mitra

5%

Cocok untuk Anda yang ingin merekomendasikan Probolinggo Rafting kepada pelanggan atau jaringan Anda.

  • Komisi 5% dari penjualan yang memenuhi ketentuan
  • Cocok untuk komunitas, individu dan jaringan bisnis
  • Informasi paket dan bantuan dari tim
  • Tidak perlu mengelola sistem pemesanan sendiri

🚀 Agent

20%

Cocok untuk travel agent, tour operator atau pihak yang aktif menjual paket wisata.

  • Komisi 20% sesuai ketentuan program
  • Cocok untuk penjualan secara aktif
  • Dapat memasarkan berbagai paket yang tersedia
  • Data penjualan dapat dicatat dalam sistem

Pertanyaan Umum

Informasi dasar mengenai program Agent & Mitra.

Apa itu program Agent & Mitra?

Program kerja sama bagi pihak yang ingin membantu memasarkan paket Probolinggo Rafting.

Berapa komisi Mitra?

Komisi Mitra adalah 5% sesuai ketentuan program.

Berapa komisi Agent?

Komisi Agent adalah 20% sesuai ketentuan program.

Apakah pendaftaran langsung aktif?

Tidak. Data pendaftaran masuk dengan status Menunggu dan perlu diverifikasi terlebih dahulu.

Bagaimana saya akan dihubungi?

Anda dapat memilih WhatsApp, Telepon atau Email sebagai pilihan kontak saat mendaftar.
